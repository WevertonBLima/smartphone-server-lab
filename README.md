# smartphone-server-lab
A laboratory where a smartphone will be used to create a server for studying security, operating systems, networks, automation, containers, etc.

A study project focused on transforming an Android smartphone into a server using Linux environments—initially via Termux and UserLAnd.

The goal is to gain hands-on experience with:

- Linux
- Networking
- Server administration
- SSH
- HTTP/HTTPS
- Processes and services
- Security
- Automation
- Monitoring

The project will be developed progressively, documenting configurations, tests, issues encountered, and solutions.

Note: It will also be used for personal purposes.
