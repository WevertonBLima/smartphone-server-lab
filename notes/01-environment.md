# 01 — Environment

## Overview

This document describes the environment used throughout the Smartphone Server Lab.

The laboratory uses an Android smartphone running Termux as the main experimental environment.

The purpose of documenting the environment is to make the laboratory easier to reproduce and understand.

---

## Hardware and Operating System

The laboratory is running on:

- Device: Android smartphone, moto g42
- RAM: 4 GB
- ROM: 128 GB
- Operating System: Android 13
- Architecture: ARM64 (`aarch64`)
